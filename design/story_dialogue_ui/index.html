# GOAL: Redesign Dialogue Reader UI & Spacing in React Native / Expo

We are updating the Story Reader screen to a high-utility layout that balances narration with dialogue, supports speech/narrative choices, dynamically color-codes characters, and features an inline shimmer loading transition during story continuation.

### 1. Spacing & Unified Typography (High Utility, Equal Weight)
- Grid Layout: Screen padding is `12px`. Vertical gap between dialogue rows and narrative blocks is set to `8px`.
- Narration vs. Speech Bubble Text: Both blocks MUST share identical font sizes (`13px`), line-heights (`1.6`), and primary text color tokens (e.g., solid `#000000` / `#ffffff`) so narration is not visually diminished.
- Alignment Grid: Narrative blocks have `marginLeft: 36` to perfectly line up with dialogue speech bubbles (which sit next to `28x28` avatars plus `8px` flexbox gap).

### 2. Dialogue Bubble Geometry & Color-Coding
- Asymmetric Incoming Tail: Dialogue bubbles use `borderRadius: 12` except for the top-left corner (near the avatar) which is set to `4` (`borderTopLeftRadius: 4`) to form a clean incoming speech tail.
- Translucent Tint Backing: Bubble styles must use a soft background fill (4% opacity in light mode, 8% in dark mode) and a matching thin `1px` border (12% opacity in light mode, 20% in dark mode) matching the character's accent theme. No heavy shadows.
- Dynamic Speaker Color Mapping: Map character names dynamically as they are encountered in the story sentences to one of 5 visual theme colors (blue, orange, purple, pink, teal) to ensure different characters never share the same bubble highlights.
- Dialogue Speaker Inheritance: Consecutive dialogue paragraphs without speaker attributes must programmatically inherit the speaker of the previous dialogue line to prevent split character names/colors.

### 3. Speech vs. Narrative User Selection
- Clean Quote Stripping: Clean all double-quotes from the user's selected choice reply string dynamically at runtime.
- Spoken Choice: Rendered inside a right-aligned outgoing bubble (`.user-bubble`) styled with a soft green background fill, green border, generous padding (`8px 12px`), asymmetric outgoing corner radius (`borderTopRightRadius: 4`), and a soft green shadow glow (`shadowColor: '#34c759', shadowOffset: { width: 0, height: 2 }, shadowOpacity: 0.08, shadowRadius: 6`).
- Narrative Choice: If a choice represents a non-spoken action (e.g., `isSpeech: false`), render it inline as a regular narrative block in italics highlighted in accent blue (*You decided to: [action text]*), aligned to the `36px` left margin.

### 4. Inline Generation Loading Shimmer (Network Latency)
- Transition Flow:
  1. Collapsing: User clicks a choice button -> collapse/fade out choices container.
  2. Answer Insert: Immediately append the user reply (bubble or action block) and trigger a smooth viewport scroll.
  3. Shimmer Loading: Instantly render a compact inline skeleton loader below the user reply. The loader must fade in smoothly and represent: a feedback card placeholder, a dialogue row placeholder (avatar + bubble), and a narrative line.
  4. Resolving: Simulate 1.5s latency, swap the shimmer with actual AI feedback and continuation lines, then scroll the view down smoothly.
