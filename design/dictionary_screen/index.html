Dictionary Screen Design Notes

Reference notes for the offline dictionary catalog, explicit word states, filters, and details drawer.

1. VOCABULARY STATUS MODELS:
Show each word with one of these explicit state tags:
- UNSEEN: Word has never been presented in a card practice session.
- SKIPPED: User swiped LEFT on new card. User already knows the word; it is not learned.
- LEARNING: User swiped RIGHT on new card. Added to active daily study queue.
- IN_REVIEW: Same-day learning card swiped LEFT. Marked learned, enters scheduled repetitions (e.g. tracking cycle: 1 to configured max).
- MASTERED: Word completed all repetitions successfully and is omitted from regular review.

2. COMPONENT PRESENTATION & SEARCH:
- iOS Search Bar: Magnifying glass search bar for word and translation lookup.
- CEFR scroll bar: [All | A1 | A2 | B1 | B2 | C1] horizontal scroll bar selector matching colored tags.
- Segmented Status control: Custom Segmented Control [All | Unseen | Study Queue (Learning/In Review) | Mastered] with sliding highlight.
- Dynamic List cells: Shows word spelling, POS italic label, IPA transcription, translation, CEFR badge, and dynamic Status Tag (e.g. "Review Cycle 2/5", "Learning", "Skipped", "Unseen").

3. PHYSICAL WORD INTERACTIONS:
- Tapping a cell scales down to 0.97 and slides up a frosted Liquidglass Bottom Sheet.
- Pronunciation control: Tapping speaker icon plays the word pronunciation.
- State display: The Bottom Sheet can show the current state and next action hint, but the main learning flow remains the swipe card session.
