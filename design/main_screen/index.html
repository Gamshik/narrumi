Main Screen Design Notes

Reference notes for the main screen layout, card-session entry point, learning progress, and review states.

1. THEME & COLORS:
- Primary Accent: #007aff (light), #0a84ff (dark)
- Success: #34c759 (light), #30d158 (dark)
- Warning/Phonetics: #ff9500 (light), #ff9f0a (dark)
- Background Primary: #f2f2f7 (light), #000000 (dark)
- Card Primary: #ffffff (light), #1c1c1e (dark)
- Text Primary: #000000 (light), #ffffff (dark)
- Text Secondary: rgba(60,60,67,0.6) (light), rgba(235,235,245,0.6) (dark)

2. LACONIC MAIN SCREEN STRUCTURE:
- Screen View: Scrollable content with padding-bottom: 96 to prevent floating tab bar blocking contents.
- Minimalist Header: Shows greeting, streak metric, and circular profile avatar.
- Progress Card: Shows daily goal status e.g., "Goal: 3/5 words learned". Contains a circular progress indicator.
- Two Primary Action Cards:
  - "Study New Words" (shows: "5 new cards waiting"). Opens a fullscreen Card Swipe overlay.
  - "Review Due Cards" (shows: "12 cards due"). Opens a fullscreen Card Swipe overlay.
- Story Generator Card:
  - Shows locked state until today's word goal is reached.
  - Tapping opens a dedicated frosted Bottom Drawer overlay where the user selects a genre and starts text creation.
- Connectivity: If offline, the generation button in the overlay displays a warning explaining that text creation requires internet.

3. CARD SWIPE SESSION FLOW:
- New Cards Session:
  - Swipe LEFT (Skip): Word is marked as `Skipped` (user already knows it), skipped from session, and not learned.
  - Swipe RIGHT (Learn): Word is marked as `Learning` (added to today's active learning session).
- Same-Day Learning Cards Session:
  - Swipe LEFT (Learned): Word is marked as `In Review` (learned and enters review cycle).
  - Swipe RIGHT (Keep Learning): Word remains in today's active session and reappears until learned.
- Review Cards Session:
  - Swipe LEFT (Remembered): Word advances one review cycle.
  - Swipe RIGHT (Forgotten): Word moves back one review cycle. Reschedules next review using the previous cycle's delay.
- Physics Specifications: Cards rotate slightly while dragging horizontally and slide away with a spring animation when released. Display overlay stamp tags "KNOW", "LEARN", or "LEARNED" depending on drag direction.

4. SETTINGS VIEW SPECIFICATIONS:
- CEFR level selector: Custom Segmented Control [A1 | A2 | B1 | B2 | C1] with sliding highlight.
- Goal Sliders: Configure daily word goal (3 to 20, default 5) and repetitions for mastery (2 to 8, default 5).
- Network Status: Visible state for online/offline behavior.

Architectural Card-Rules

Binds and Constraints:

Daily word goal is bounded strictly between 3-20 words. Mastery repetitions are bounded between 2-8 repetitions.

Review Scheduling Logic:

First review is scheduled 30 minutes after marked as learned. If a review card is forgotten, return it to cycle N-1 and apply the delay assigned to that previous cycle.
