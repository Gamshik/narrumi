# Context-English: Apple UI Design System & Styling Guidelines

This handbook serves as the **canonical design system reference** for the Context-English MVP application. When creating UI components, screens, or layouts, contributors **MUST strictly adhere** to the visual tokens, structures, and interaction patterns documented here.

---

## 1. Core Design Philosophy

*   **Authentic Apple Aesthetic**: Follow Apple’s Human Interface Guidelines (HIG). The UI must be clean, light, and functional.
*   **No "AI Gradient Bloat"**: Avoid heavy neon gradients, excessive glowing shadows, or overcrowded dashboard designs commonly generated by modern AI. Keep backgrounds clean and use translucency for depth.
*   **Adaptive Theme Support**: The UI must support seamless transitions between Light and Dark mode using semantic tokens.
*   **Physical Micro-Interactions**: Interactive elements must respond to user input using spring-like animations (e.g., scaling down slightly on tap) rather than simple linear transitions.

## 4. Liquidglass Material (Translucency Formula)

Liquidglass components simulate frosted glass overlays using precise layers of opacity, blur, fine borders, and drop shadows.

```css
/* Liquidglass Thin Overlays (Standard cards, tooltips) */
.liquidglass-thin {
    background-color: rgba(255, 255, 255, 0.7);
    backdrop-filter: blur(20px);
    -webkit-backdrop-filter: blur(20px);
    border: 1px solid rgba(255, 255, 255, 0.4);
    box-shadow: 0 8px 32px rgba(0, 0, 0, 0.06);
}
.dark-theme .liquidglass-thin {
    background-color: rgba(28, 28, 30, 0.65);
    border: 1px solid rgba(255, 255, 255, 0.08);
    box-shadow: 0 8px 32px rgba(0, 0, 0, 0.35);
}

/* Liquidglass Thick Overlays (Bottom sheets, modal dialogs) */
.liquidglass-thick {
    background-color: rgba(255, 255, 255, 0.85);
    backdrop-filter: blur(25px);
    -webkit-backdrop-filter: blur(25px);
    border: 1px solid rgba(255, 255, 255, 0.6);
    box-shadow: 0 12px 40px rgba(0, 0, 0, 0.08);
}
.dark-theme .liquidglass-thick {
    background-color: rgba(28, 28, 30, 0.8);
    border: 1px solid rgba(255, 255, 255, 0.1);
    box-shadow: 0 12px 40px rgba(0, 0, 0, 0.45);
}
```

*React Native Implementation Note: Use `Expo BlurView` with `intensity={75}` (light) or `intensity={50}` (dark) combined with absolute positions, border radius, and a thin border color overlay to replicate this.*

## 5. Floating Pill Tab Bar (Expo / Telegram style)

Instead of traditional full-width tab bars attached to the bottom edge, implement a **floating capsule tab bar** that hovers above the scrollable content.

### Specifications:
*   **Dimensions & Placement**:
    *   Position: Floating (`absolute`).
    *   Bottom margin: `20px` (above the Home Indicator).
    *   Side margins: `16px` on the left and right (capsule width: `100% - 32px`).
    *   Height: `62px` with a perfect round border-radius (`border-radius: 99px`).
*   **Visual Style**:
    *   Must use the **Liquidglass Thin** formula.
    *   Inner glow: In dark mode, add a subtle inner border overlay (`rgba(255,255,255,0.03)`).
*   **Active Tab Capsule Highlight**:
    *   The active icon **MUST NOT** just change color. It must sit inside a **circular backing capsule** (`.nav-icon-wrapper`).
    *   Pill dimensions: `36px` x `36px` circle (`border-radius: 50%`).
    *   Light mode active: Background `rgba(0, 122, 255, 0.1)` (light tint) and icon color `--sys-blue`.
    *   Dark mode active: Background `rgba(10, 132, 255, 0.16)` (deeper tint) and icon color `--sys-blue`.
    *   Active scale: Slightly scaled up (`transform: scale(1.05)`) with a soft drop shadow on the active icon container.
*   **Scroll Area Padding Rule**:
    *   To prevent the floating tab bar from blocking the final cards on a screen, the main scroll container (`.screen-container`) **MUST** include a large bottom padding: `padding-bottom: 96px`.

## 6. Snappy Spring Micro-interactions (Physics Guidelines)

All interactive elements (buttons, segmented items, quiz selections) must avoid static transitions and implement **tactile physics-based scaling**:

1.  **Press States (Active)**:
    *   On press, scale down the element immediately: `transform: scale(0.96)`.
    *   Slightly lower the opacity: `opacity: 0.85`.
    *   Spring easing: `cubic-bezier(0.16, 1, 0.3, 1)` (snappy spring curve).
2.  **Toggle Switches**:
    *   Custom green tracks (`--sys-green`) with a high-contrast sliding white circular knob (`box-shadow: 0 3px 8px rgba(0,0,0,0.15)`).
    *   Sliding animation: Snappy spring translation (`cubic-bezier(0.16, 1, 0.3, 1)`).
3.  **Physical Error Feedback (Haptic Shake)**:
    *   When a user clicks an incorrect quiz answer, the option card turns `--sys-red` and the entire container card triggers a **haptic shake animation** (visual vibration):
        ```css
        @keyframes shake {
            0%, 100% { transform: translateX(0); }
            20%, 60% { transform: translateX(-6px); }
            40%, 80% { transform: translateX(6px); }
        }
        ```
4.  **Physical Success Feedback (Soft Pulse)**:
    *   When the correct quiz answer is selected, highlight the option card in green (`rgba(52, 199, 89, 0.12)`) and trigger a soft bounce animation:
        ```css
        @keyframes bounceIn {
            0% { transform: scale(0.97); }
            50% { transform: scale(1.02); }
            100% { transform: scale(1); }
        }
        ```

## 7. Interactive MVP Component Blueprints

### A. Inline Tap-to-Translate Tooltips
*   Tapping any underlined word (`trans-word`) opens an elegant Liquidglass tooltip box.
*   **Alignment**: Compute the absolute width of the word. Center-align the tooltip directly over/under the word horizontally.
*   **Dismissal**: The tooltip has pointer-events active, but tapping *anywhere* else outside the tooltip instantly triggers a dismiss transition.
*   **Scale Animation**: Tooltips fade and scale into view: from `scale(0.8) translateY(10px)` to `scale(1) translateY(0)`.

### B. Karaoke Text-to-Speech Highlighting
*   The daily story text is split into distinct sentences (`story-sentence`).
*   **Active Reading**: The active read sentence turns opaque (`opacity: 1`) and gets a soft highlighted backing (`rgba(0, 122, 255, 0.12)` in light, or deep translucent blue backing in dark).
*   **Unread States (Dimming)**: All unread or previously read sentences are slightly dimmed to `opacity: 0.45` to focus the user's attention.

### C. Grammar Bottom Drawer (BottomSheet)
*   Long-pressing or tapping the `?` trigger next to a sentence slides up a frosted-glass Bottom Sheet from the very bottom of the screen.
*   **Structural elements**:
    *   Drag handle bar (`width: 36px`, `height: 5px`, `opacity: 0.2`) centered at the top.
    *   Clean Close button (`✕`) at the top right of the sheet.
    *   Highlighted sentence block using a thick left border (`border-left: 3px solid var(--sys-blue)`).
*   **Animation**: Slides up vertically: from `translateY(100%)` to `translateY(0)` with spring easing (`cubic-bezier(0.15, 0.85, 0.35, 1)`).
