# User Flow Visual Schema — Context-English Series MVP

## 1. Общая Карта Пользовательского Пути

```mermaid
flowchart TD
    A["Пользователь открывает приложение"] --> B{"Первый вход?"}

    B -- "Да" --> C["Короткое знакомство с идеей"]
    C --> D["Выбор уровня английского"]
    D --> E["Главный экран"]

    B -- "Нет" --> E

    E --> F{"Есть созданные сериалы?"}
    F -- "Нет" --> G["Создать первый сериал"]
    F -- "Да" --> H["Продолжить последний сериал"]

    E --> I["Создать новый сериал"]
    E --> J["Открыть список сериалов"]
    E --> K["Открыть словарь"]
    E --> L["Открыть настройки"]

    G --> M["Одноэкранная настройка сериала"]
    I --> M
    H --> N["Подготовка новой серии"]
    J --> O["Выбор сериала"]
    O --> N

    M --> N
    N --> P["Выбор слов для серии"]
    P --> Q["Создать серию"]
    Q --> R["Читать и слушать серию"]
    R --> S["Взаимодействовать с сюжетом"]
    S --> T["Получить продолжение и мягкую коррекцию"]
    T --> U["Конец серии с интригой"]

    U --> V{"Что дальше?"}
    V -- "Продолжить сериал" --> N
    V -- "Изменить слова" --> P
    V -- "Вернуться к сериалу" --> O
    V -- "Открыть другую серию" --> J
```

## 2. Создание Сериала

```mermaid
flowchart TD
    A["Создать сериал"] --> B["Card 1: выбрать Producer или Character"]
    B --> C["Card 2: написать Idea или Generate by AI"]
    C --> D{"Idea заполнена?"}
    D -- "Нет" --> C
    D -- "Да" --> E["Card 3: добавить Characters с role/personality"]
    E --> F{"Character mode?"}
    F -- "Да" --> G["Выбрать Your character из канонического имени cast"]
    F -- "Нет" --> H{"Cast заполнен?"}
    G --> H
    H -- "Нет" --> E
    H -- "Да" --> I["Card 4: написать Title или Generate by AI"]
    I --> J{"Все четыре card заполнены?"}
    J -- "Нет" --> K["Вернуться по Back/Series setup или сохранить локальный draft"]
    J -- "Да" --> L["Сохранить сериал локально и поставить sync в очередь"]
    C -. "AI online only; меняет только Idea" .-> C
    E -. "AI online only; меняет только Characters" .-> E
    I -. "AI online only; меняет только Title" .-> I
    L --> M["Перейти к первой серии"]
```

## 3. Подготовка Серии

```mermaid
flowchart TD
    A["Пользователь хочет новую серию"] --> B["Видит выбранный сериал"]
    B --> C["Видит жанр и уровень"]
    C --> D["Видит слова, которые попадут в серию"]

    D --> E{"Что сделать?"}
    E -- "Оставить слова как есть" --> F["Создать серию"]
    E -- "Изменить слова" --> G["Выбор слов"]
    E -- "Продолжить без изменений" --> H["Оставить текущий набор"]
    E -- "Вернуться назад" --> I["Экран сериала"]

    G --> J["Выбор слов"]
    H --> F
    J --> F
```

## 4. Выбор Слов Для Серии

```mermaid
flowchart TD
    A["Выбор Story Words"] --> B["Загрузить количество из Settings"]
    B --> C["Создать или восстановить столько же редактируемых слотов"]
    C --> D{"Что изменить?"}

    D -- "Оставить набор" --> E["Готово"]
    D -- "Заменить одно слово" --> F["Выбрать слово из Oxford 5000"]
    D -- "Случайная замена" --> G["Заменить только выбранный слот"]
    D -- "Перемешать все" --> H["Создать новый набор того же размера"]

    F --> C
    G --> C
    H --> C
    E --> I["Вернуться к подготовке эпизода"]
```

## 5. Подготовка, Создание И Чтение Серии

```mermaid
flowchart TD
    A["Открыть подготовку серии"] --> B["Заполнить свою идею и опциональные опоры"]
    B --> C{"Нужна помощь AI?"}

    C -- "Да" --> D{"Есть интернет?"}
    D -- "Нет" --> E["Показать, что AI-действие доступно онлайн"]
    E --> B
    D -- "Да" --> F{"Какая стратегия выбрана?"}
    F -- "Fill gaps" --> G["Заполнить только пустые поля"]
    F -- "Refine" --> H["Заполнить пробелы и выборочно улучшить полезные поля"]
    F -- "Rebuild" --> I["Создать итоговый черновик заново"]
    G --> J["Пользователь редактирует результат или нажимает Undo"]
    H --> J
    I --> J

    C -- "Нет" --> J
    J --> K{"Обязательные поля готовы?"}
    K -- "Нет" --> L["Save draft: сохранить локально без сети"]
    L --> M["Вернуться позже к тому же черновику"]
    M --> B

    K -- "Да" --> N["Проверить и создать серию"]
    N --> O{"Серия создана?"}
    O -- "Нет" --> P["Оставить локальный черновик и показать ошибку"]
    P --> B
    O -- "Да" --> Q["Удалить setup-черновик и открыть серию"]
    Q --> R["Читать сцену"]
    R --> S["Слушать озвучку"]
    R --> T["Тапнуть слово для перевода"]
    R --> U["Дойти до интерактива"]
```

## 6. Интерактив Внутри Серии

```mermaid
flowchart TD
    A["Интерактив серии"] --> B{"Тип действия"}

    B -- "Выбрать вариант" --> C["Пользователь выбирает действие"]
    C --> D["История реагирует на выбор"]

    B -- "Написать короткий ответ" --> E["Пользователь пишет фразу"]
    E --> F{"Есть интернет?"}
    F -- "Нет" --> G["Ответ сохранен, коррекция позже"]
    F -- "Да" --> H["Получить мягкую коррекцию"]
    H --> I["История продолжается"]

    B -- "Задать вопрос персонажу" --> J["Пользователь пишет вопрос"]
    J --> K{"Есть интернет?"}
    K -- "Нет" --> L["Показать, что чат доступен онлайн"]
    K -- "Да" --> M["Персонаж отвечает"]

    B -- "Обсудить сцену" --> N["Пользователь обсуждает сюжет с AI"]
    N --> O{"Есть интернет?"}
    O -- "Нет" --> P["Показать offline-состояние"]
    O -- "Да" --> Q["AI отвечает в рамках истории"]

    D --> R["Продолжение серии"]
    G --> R
    I --> R
    M --> R
    Q --> R
    R --> S["Cliffhanger"]
```

## 7. Конец Серии

```mermaid
flowchart TD
    A["Серия заканчивается"] --> B["Показать интригу"]
    B --> C["Показать легкое резюме"]
    C --> D["Какие слова встретились"]
    C --> E["Какие слова пользователь открывал"]
    C --> F["Какие слова пользователь использовал"]
    C --> G["Без долга повторений"]

    G --> H{"Что хочет пользователь?"}
    H -- "Следующая серия" --> I["Подготовка новой серии"]
    H -- "Изменить слова" --> J["Выбор слов"]
    H -- "К списку серий" --> K["Экран сериала"]
    H -- "Перечитать прошлое" --> L["Список эпизодов"]
```

## 8. Экран Сериала

```mermaid
flowchart TD
    A["Экран сериала"] --> B["Название и жанр"]
    B --> C["Последняя интрига"]
    C --> D["Список серий"]
    D --> E["Слова сериала"]

    E --> F{"Действие пользователя"}
    F -- "Продолжить" --> G["Подготовка новой серии"]
    F -- "Открыть серию" --> H["Чтение серии"]
    F -- "Изменить сериал" --> I{"Есть созданные эпизоды?"}
    F -- "Настроить слова" --> J["Выбор слов"]
    F -- "Удалить сериал" --> K["Подтверждение удаления"]

    I -- "Нет" --> N["Редактируемая одноэкранная настройка"]
    I -- "Да" --> O["Настройка только для чтения"]

    K --> L{"Удалить?"}
    L -- "Нет" --> A
    L -- "Да" --> M["Вернуться на главный экран"]
```

## 9. Словарь И Настройки

```mermaid
flowchart TD
    A["Словарь"] --> B["Поиск слова"]
    A --> C["Фильтр по уровню"]
    A --> D["Открыть слово"]
    D --> E{"Что сделать со словом?"}
    E -- "Добавить в Today’s Words" --> F["Слово доступно для серий сегодня"]
    E -- "Добавить в сериал" --> G["Слово связано с выбранным сериалом"]

    I["Настройки"] --> J["Изменить уровень"]
    I --> K["Изменить предпочтения"]
    I --> L["Аккаунт, статус синхронизации, Sync Now и выход"]
```
