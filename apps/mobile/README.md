# Context English Mobile

Expo React Native application for the Context-English MVP.

## Commands

- `npm run start` - start Expo development server.
- `npm run ios` - start Expo for iOS through Expo Go.
- `npm run lint` - run ESLint.
- `npm run test` - run the mobile TypeScript test suite.
- `npm run typecheck` - run TypeScript without emitting files.
- `npm run build` - export the Expo app bundle.
