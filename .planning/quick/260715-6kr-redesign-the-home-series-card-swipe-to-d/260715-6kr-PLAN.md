# Redesign the Home series-card swipe-to-delete interaction

## Goal

Replace the mechanical JS-driven reveal with a native Sorbet interaction that remains reliable during vertical scrolling, exposes deletion clearly, preserves confirmation, supports accessibility and Reduce Motion, and gives the destructive state a memorable soft-pop visual identity.

## Task 1: Define and test swipe behavior

- Delegate drag ownership, velocity, and snapping to Expo-compatible native gesture and Reanimated primitives.
- Add pure typed presentation and ownership helpers for the visible action and one-open-row state.
- Cover geometry, progressive affordance, and stale native close callbacks with Node tests.

## Task 2: Build and integrate the interaction

- Move the series card swipe UI into its own component folder.
- Render a single fixed-width destructive lane beneath an opaque, geometry-stable card; reveal it only through foreground translation.
- Build the lane as one layered berry material with depth shading, grape halo, traveling sheen, an inflated trash core, and sequential caption reveal.
- Compress only the visual core on delete press so the full-width destructive geometry remains gap-free.
- Keep one card open at a time, close predictably on card taps and scrolling, prevent accidental navigation after a drag, preserve the confirmation route, and expose an accessibility delete action.
- Respect the existing Sorbet tokens, light/dark themes, Expo Managed Workflow, and Reduce Motion.
