<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Preferences -> Settings UI | Local preferences are untrusted display data and must be updated through application services. |
| Sync operation -> Settings UI | Sync results cross application/infrastructure boundaries and must be summarized safely. |
| Auth session -> Settings UI | Account identity and sign-out state must stay behind auth hooks. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-02-08-01 | Tampering | Learning preference persistence | medium | mitigate | Preserve existing `preferredGenre` value when visible genre control is removed; run lint/typecheck. |
| T-02-08-02 | Information Disclosure | Sync result display | low | mitigate | Continue rendering safe status labels/descriptions and avoid raw internal payloads. |
| T-02-08-03 | Denial of Service | Manual sync button | low | mitigate | Preserve disabled state while `isSyncing` and keep manual sync accessible in compact layout. |
| T-02-08-SC | Tampering | npm installs | low | accept | No package installs or dependency changes are planned. |
</threat_model>
