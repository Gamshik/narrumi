## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| User setup input -> validation/use cases | Setup text, role, and characters remain untrusted and validated before save/generation. |
| Generate action -> AI boundary | Setup generation must stay behind the existing application use case and Edge Function path. |
| Local series details -> presentation | Series, episode, and memory records are untrusted display data; memory must remain available to application code but hidden from this screen. |
