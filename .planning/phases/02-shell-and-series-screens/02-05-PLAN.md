<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Preferences -> Settings UI | Local preferences are untrusted display data and must be updated through application services. |
| Sync operation -> Settings UI | Sync results cross application/infrastructure boundaries and must be summarized safely. |
| Auth session -> Settings UI | Account identity and sign-out state must stay behind auth hooks. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-02-13 | Tampering | Learning preferences update | medium | mitigate | Preserve optimistic update/rollback through `localAppServices.updateLearningPreferences.execute` and run lint/typecheck. |
| T-02-14 | Information Disclosure | Sync result display | low | mitigate | Render existing safe sync labels/descriptions; avoid raw internal payloads in status rows. |
| T-02-15 | Denial of Service | Settings scroll/tab clearance | low | mitigate | Preserve screen content bottom padding and include manual small-viewport UAT. |
| T-02-SC | Tampering | npm installs | low | accept | No package installs or dependency changes are planned. |
</threat_model>
