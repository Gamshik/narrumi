# 03-02-PLAN: Authenticated root bootstrap provider and non-blocking sync

## Goal
Implement a `BootstrapProvider` that hydrates local user session data and initiates a non-blocking background sync attempt. Provide the resulting `BootstrapState` to child components in the authenticated route tree.

## Requirements
- BOOT-01
- SYNC-01
- SYNC-02
- SYNC-03

## must_haves
- Sync attempt MUST be non-blocking. It MUST run after local hydration finishes.
- The `BootstrapState` MUST be modeled as a discriminated union so that screens can pattern-match on `hydrating | ready | failed`.
- `AuthProvider` MUST NOT duplicate the startup sync trigger.

- Type `BootstrapState`
- Type `BootstrapReadyState`
