<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| AuthProvider -> BootstrapProvider | Bootstrap must only access authenticated app state after session restoration has completed. |
| Local bootstrap -> remote sync | Remote sync is best-effort and must not invalidate locally loaded settings on failure. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-03-03 | Elevation of Privilege | `_layout.tsx` provider placement | high | mitigate | Place `BootstrapProvider` inside `AuthGate` authenticated branch only, so signed-out users cannot enter authenticated bootstrap state. |
| T-03-04 | Denial of Service | startup sync orchestration | medium | mitigate | Remove duplicate AuthProvider first-sync and run one bootstrap-owned background sync attempt after local hydration. |
| T-03-05 | Tampering | sync result handling | medium | mitigate | Keep local preferences visible on failed sync and treat remote results as non-blocking diagnostics. |
| T-03-SC | Tampering | npm installs | high | mitigate | No package-manager installs are allowed in this plan; run existing package scripts only. |
</threat_model>
