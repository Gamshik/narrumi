<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Bootstrap state -> Settings controls | Settings must only render user-specific values after local bootstrap readiness. |
| Settings edits -> local persistence | User edits must persist locally first and rollback if the local write fails. |
| Sync result -> Settings warning UI | Remote sync failures are untrusted diagnostics and must not hide local settings. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-03-08 | Tampering | `SettingsScreen` preference state | medium | mitigate | Remove placeholder defaults and initialize controls only from validated bootstrap preferences. |
| T-03-09 | Repudiation | failed settings save | low | mitigate | Revert failed edits to the previous loaded values and show inline save error per D-12. |
| T-03-10 | Information Disclosure | sync/save errors | low | mitigate | Show safe concise messages; do not expose raw Supabase or storage objects. |
| T-03-SC | Tampering | npm installs | high | mitigate | No package-manager installs are allowed in this plan; run existing package scripts only. |
</threat_model>
