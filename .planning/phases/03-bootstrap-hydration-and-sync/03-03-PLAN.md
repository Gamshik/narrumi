<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Bootstrap state -> UI copy | Safe state details are rendered to the user; raw storage or SDK errors must not appear. |
| Guarded surface -> app routes | Guard must not hide unguarded app routes or accidentally expose loaded settings before hydration. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-03-06 | Information Disclosure | `BootstrapScreen` error detail | low | mitigate | Render compact safe messages from bootstrap state, not raw caught errors. |
| T-03-07 | Denial of Service | retry UI | medium | mitigate | Retry only repeats local hydration and must not block on remote sync; keep button disabled while retry is active if provider exposes retrying state. |
| T-03-SC | Tampering | npm installs | high | mitigate | No package-manager installs are allowed in this plan; run existing package scripts only. |
</threat_model>
