# 03-01-PLAN: Local-only bootstrap hydration and recovery metadata

## Goal
Extract the local preference reading logic out of `withPreSync` wrappers so that the UI can be unblocked by local state immediately, satisfying D-05. Ensure any corrupted local storage can be flagged.

## Requirements
- BOOT-02

## must_haves
- Local hydration logic MUST NOT wait for or invoke any remote sync calls.
- In case of a parse error in AsyncStorage, it MUST return `recovered: true` instead of silently swallowing the data loss.
- `hydrateBootstrapSession.ts` MUST create new defaults if `preferences: undefined` is returned from storage.

## Artifacts this phase produces
- Type `BootstrapHydrationResult`
- Type `BootstrapPreferenceStore`
- Type `HydrateBootstrapSession`
- Function `createHydrateBootstrapSession`
- Export `hydrateBootstrapSession` in `localAppServices.ts`
