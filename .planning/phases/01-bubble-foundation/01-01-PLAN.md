## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Theme tokens -> presentation components | Visual constants cross into reusable UI; bad values can make text unreadable or controls inaccessible. |
| Safe-area inset -> layout helper | Device-provided inset values influence floating navigation placement and scroll padding. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |

| T-01-01 | Denial of Service | `tokens.ts` light/dark colors | medium | mitigate | Use paired semantic light/dark token keys and typechecking so shared primitives do not rely on light-only hardcoded colors. |
| T-01-02 | Tampering | `layout.ts` inset calculation | low | mitigate | Keep the helper pure and test zero and large bottom inset cases so arbitrary spacing constants do not cover scroll content. |
| T-01-SC | Tampering | npm installs | low | accept | No package installs or version changes are planned in this file set. |
