## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| User touch -> presentation callback | Press/toggle interactions cross from shared controls to screen-owned callbacks. |
| Theme tokens -> rendered controls | Light/dark semantic tokens determine visibility and accessibility of press, toggle, and sheet surfaces. |
| Native form sheet -> React Native content | iOS formSheet height calculation depends on React Native content measuring intrinsically. |
| Presentation layer -> application/domain/infrastructure | Gap fixes must not cross into persistence, sync, AI, Supabase, native projects, or domain rules. |

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-01-09 | Denial of Service | `JellyPressable`, `MobileApp.styles.ts` | low | mitigate | Keep stronger press feedback transform/opacity-only so controls remain responsive and layout-stable. |
| T-01-10 | Spoofing | `BubbleToggle` | medium | mitigate | Set `accessibilityRole="switch"` and checked/disabled accessibility state so the custom control communicates its real state. |
