<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Screen state -> shared primitives | Screen-owned display state enters reusable UI components as props. |
| User touch -> callbacks | Press events cross from presentation controls back to screen/application-owned intent handlers. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-01-03 | Tampering | `BubbleButton`, `BubblePill` | medium | mitigate | Forward `disabled` to the underlying Pressable and expose `accessibilityState` so disabled/offline visual states cannot look active. |
| T-01-04 | Information Disclosure | shared primitives | medium | mitigate | Keep primitives free of infrastructure, Supabase, storage, AI, raw error, and domain imports; they render caller-provided content only. |
| T-01-05 | Denial of Service | shared primitive colors | medium | mitigate | Consume semantic light/dark theme tokens so shared controls remain readable in both appearances. |
| T-01-SC | Tampering | npm installs | low | accept | No package installs or version changes are planned in this file set. |
</threat_model>
